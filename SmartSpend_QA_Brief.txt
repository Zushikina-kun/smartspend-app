WHAT IS SMART SPEND?
Smart Spend is an AI-powered personal finance tracker for Android,
built for everyday Filipino users. It helps you record, analyze,
and manage your spending with minimal effort — using voice, camera,
or just typing naturally.

HOW TO GET STARTED
───────────────────────────────────────────────────────────────
1. Install app-arm64-v8a-release.apk on your Android phone
2. Create an account OR tap "Try Demo" to explore with sample data
3. Complete the short setup (account type, income, currency)
4. The feature tour will walk you through the basics

───────────────────────────────────────────────────────────────
AI ASSISTANT — WHAT IT CAN DO
───────────────────────────────────────────────────────────────
Just talk to it naturally in English (or Filipino if you prefer).

  Log expenses:     "I spent 85 pesos on lunch"
  Set budgets:      "Set my food budget to 3000"
  Track debts:      "I borrowed 500 from John"
  Add income:       "I received 1500 allowance"
  Create goals:     "I want to save 10000 for a new phone"
  Add recurring:    "Add Netflix 299 monthly"
  Ask questions:    "How am I doing this month?"
                    "List my expenses"
                    "Where am I overspending?"

The AI responds in English by default. It switches to Filipino
only if you write full Filipino sentences or explicitly ask it to.

───────────────────────────────────────────────────────────────
THINGS TO NOTE
───────────────────────────────────────────────────────────────
• All amounts are in Philippine Peso (₱) by default
  — changeable in Profile → Currency & Region

• Data is saved locally AND synced to your account via Firebase
  — logging out pushes everything to the cloud first

• Demo mode uses sample data — nothing saved to a real account

• Backup exports a JSON file via the share sheet — save to phone storage,
  email, Google Drive, Dropbox, or anywhere you want
  (Profile → Backup Data)

• Restore picks a .json backup file from your device storage
  (Profile → Restore from Backup)

• Daily AI limit: 60 messages per day (resets at midnight UTC)

───────────────────────────────────────────────────────────────
FOUND A BUG?
───────────────────────────────────────────────────────────────
Go to:  AI screen → ⋮ menu → Export Debug Log

Share the .txt file — it contains all your data and chat history
for easy diagnosis. You can also find it at:
  Profile → Export Debug Log

───────────────────────────────────────────────────────────────
KNOWN LIMITATIONS (not bugs)
───────────────────────────────────────────────────────────────
• Profile photo does not sync across devices
  (Firebase Storage requires a paid plan)

• AI features require an internet connection

• Recurring transactions do not auto-log in the background
  (tap "Log Now" manually from Profile → Recurring Transactions)

• App stays logged in until you explicitly log out
  (this is intentional — Smart Spend is a tracker, not a payment app)

• App Lock is available — go to Profile → App Lock to set a 4-digit PIN
  (biometric unlock auto-prompts if your device supports it — works with
   optical in-display fingerprint, face unlock, and device PIN/pattern)
  (lock screen appears after 3+ minutes in background or full app close)
  (does NOT trigger during brief interruptions like share sheets or camera)
