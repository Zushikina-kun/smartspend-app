# SmartSpend v3.2.0 Release Notes

**Release Date:** November 15, 2024  
**Version Code:** 111  
**Status:** Production Ready  
**Build Size:** 119.8 MB

---

## 🎯 Overview

SmartSpend v3.2.0 introduces the **Government Contributions Tracker** — making SmartSpend the first Filipino personal finance app to provide dedicated tracking for mandatory SSS, PhilHealth, and Pag-IBIG contributions. This release also includes important accessibility improvements for users with smaller devices.

---

## ✨ What's New

### 🏛️ Government Contributions Tracker

Track your mandatory government contributions all in one place:

- **Three New Categories:** SSS, PhilHealth, Pag-IBIG
  - Auto-available in all expense logging flows (manual, voice, OCR, AI chat)
  - Integrated with existing category system
  - Full currency formatting support

- **Dashboard Widget**
  - Shows total government expenses year-to-date
  - Auto-hides when no contributions logged
  - Tappable to open full Government Contributions screen

- **Government Contributions Screen** (New)
  - Year-to-date totals per agency
  - Year selector for viewing historical data
  - Per-year breakdown showing contributions by agency
  - SSS pension estimator calculator
  - Direct portal links:
    - [sss.gov.ph](https://sss.gov.ph)
    - [philhealth.gov.ph](https://philhealth.gov.ph)
    - [pagibigfund.gov.ph](https://pagibigfund.gov.ph)

- **Tools Hub Integration**
  - Accessible from Home screen Quick Access
  - Organized under FINANCES category
  - Matches existing SmartSpend UI patterns

**Use Cases:**
- Freelancers tracking quarterly SSS/PhilHealth/Pag-IBIG payments
- Employees verifying employer contributions
- OFWs managing voluntary contributions while abroad
- Budget planning with government mandatories included
- Year-end tax preparation with complete contribution records

## 🚀 Upgrade Instructions

### For New Users
1. Download `app-release.apk` from [GitHub Releases](https://github.com/Zushikina-kun/smartspend-app/releases/tag/v3.2.0)
2. Enable "Install from Unknown Sources" in Android settings
3. Install APK
4. Open app and start tracking

### For Existing Users
1. Download and install new APK (will update existing installation)
2. All your data will be preserved automatically
3. New categories (SSS, PhilHealth, Pag-IBIG) will appear in category dropdowns
4. Access Government Contributions from Home → Tools hub

**Note:** No special migration steps needed. Update is seamless.
