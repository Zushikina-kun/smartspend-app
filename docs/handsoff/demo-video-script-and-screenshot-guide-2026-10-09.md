### RECORDING TIPS

**Screen recorder settings:**
- Resolution: 1080p (do NOT use 4K — file too large, unnecessary)
- Frame rate: 60fps if your phone supports it, 30fps is fine
- Audio: Silent (no mic) — add text overlays in editing instead
- Duration: Record each shot separately, edit together

**Shot flow for each take:**
1. Get to the right screen first
2. Pause 1 second
3. Perform the action slowly and deliberately (AI chat: type slowly)
4. Pause 1 second after the result appears
5. Stop recording

**Editing (CapCut — free, works well):**
- Import all clips in order
- Trim start/end pause to 0.5s each
- Add text overlays: Font = bold, Color = white, Background = dark semi-transparent pill
- Add transition: "Fade" between shots (0.3s)
- Background music: CapCut free library → "Upbeat" or "Tech" category, volume 20%
- Export: 1080p MP4

- Demo data loaded ("Try Demo")

- Notifications: none visible (DND on)
- Battery: ideally 100% or hidden

### Google Play Store specs
- Size: minimum 1080 × 1920px (9:16 portrait)
- Format: PNG or JPG
- Max: 8 screenshots recommended (minimum 2)
- Device frame: optional but looks professional. Free tool: **Mockuphone.com** → select Pixel 9 frame
